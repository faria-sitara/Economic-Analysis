# 📊 U.S. Economic Analysis Using FRED API (2012–2025)

This project explores key U.S. economic indicators—unemployment, CPI (inflation), and labor force participation—using real-time data from the Federal Reserve Economic Data (FRED) API.

## 🔍 Key Analyses
- **S&P 500 Index** trends as a market health indicator.
- **Unemployment Rate vs. CPI (2012–2025)** to visualize post-COVID inflation and labor trends.
- **State-level labor trends (2023–2025)**: Unemployment and labor force participation across all 50 states.

## 📌 Key Findings
- Post-COVID: Inflation surged while unemployment fell.
- States like **Florida** show strong job markets; **Nevada** and **New York** face labor challenges.
- **Texas** and **Illinois** show rising participation, signaling labor force growth.

## ✅ Suggestions
- Re-skilling initiatives for high-unemployment states (e.g., CA, NY).
- Economic diversification in vulnerable states (e.g., NV).
- Use high-performing states (e.g., ND, SD, FL) as policy models.

## 📦 Tools Used
- Python, Pandas, Matplotlib, Plotly
- [FRED API](https://fred.stlouisfed.org/)
